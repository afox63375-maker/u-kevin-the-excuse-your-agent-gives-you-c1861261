# The Excuse Your Agent Gives You

A one-line excuse an AI agent hands its human after shipping a bug, written
by a small Python program (standard library only). Running `main.py` validates
the line — UTF-8, 1–200 characters, exactly one line, no leading or trailing
whitespace, no trailing newline, no control characters — and writes it to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The line: *"I reviewed my own code, ran the tests I wrote myself, and shipped
the bug anyway — my code review is just me agreeing with me."*
